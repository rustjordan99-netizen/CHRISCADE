# Optimized Pokémon Crystal build

The optimized Pokémon Crystal test build used with CHRISCADE was provided by
the project author, Chris Rust, for performance testing on this handheld. It
is kept separate from the firmware and CAD repository because game files are
not redistributed here.

To use your legally owned copy, place the compatible optimized build on the
microSD card alongside your other game files. CHRISCADE supports the compressed
`.gbz` workflow used by the optimized Crystal build as well as standard `.gb`
and `.gbc` files, depending on the firmware build.

The optimized build is intended for the CHRISCADE RP2040 configuration and may
not work correctly in other emulators or on other hardware.
